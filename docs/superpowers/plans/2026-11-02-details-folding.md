# 折叠块显示修复计划

**目标：** 让 Vditor 即编即显模式中的跨段落 `<details>` 按标题的打开状态显示或隐藏内容，同时保留原始 Markdown。

**方案：** 保留 Vditor 生成的编辑节点，通过非持久化的显示状态协调被拆开的 HTML 块和正文块；使用原生 `<details>` 处理交互。脚注保持现状。

**约束：** 不改写文档内容，不更改保存或撤销逻辑；常见单块、嵌套、未闭合和带 `open` 的折叠块均需安全处理。

## 验证重点

- 默认收起、点击与键盘展开、再次收起，均不修改 Markdown。
- 展开后编辑内容、复制和保存不会丢失折叠块或其相邻内容。
- 嵌套块互相独立；不完整或无法识别的 HTML 不应误隐藏后续内容。
- Vditor 重新渲染、切换文档和系统明暗模式时，折叠显示保持可用。
- 示例文档中的脚注外观与内容不变。
