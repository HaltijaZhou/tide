# 状态栏外观切换设计

## 目标

在 Tide 状态栏提供浅色、深色、跟随系统三个常驻图标，让用户无需修改系统设置即可选择外观；默认跟随系统，显式选择持久化。延续现有「潮间」明暗配色和单文件写作界面。

## 方案

使用与 Tide 笔画一致的太阳、月牙和显示器线性图标。选中项有潮青底色及短线，悬停和键盘焦点提供反馈，按钮有中文名称；状态栏狭窄时允许换行。图标组与字数和状态提示独立，避免提示文本更新时被覆盖。另一种方案是单图标展开菜单，较省空间但多一次操作；此处采用已展示并获用户认可的三个常驻图标。

偏好为 `system`、`light`、`dark`，首次及无效值回退 `system`；手动模式不受系统变化影响，恢复 `system` 后继续跟随。首次绘制前读取本机偏好；运行时同步 Tide 令牌、Vditor 外壳、正文和代码高亮，并尽力同步原生窗口标题栏。存储不可用不阻止编辑器运行，当前会话仍可切换。

切换不改变 Markdown、保存状态、撤销历史或选区。原生窗口主题 API 的异步操作按顺序执行，最终应用最新选择。所有资源保持离线，不引入运行时依赖。

发布工作流的 Release 正文只保留：`轻量级单文件 Markdown 编辑器，Typora 式即编即显，完全离线可用。` 现有版本号为 0.1.6，完成后合入 main，发布正式标签 v0.1.6，并检查 CI、Release 及 Windows 安装包。
